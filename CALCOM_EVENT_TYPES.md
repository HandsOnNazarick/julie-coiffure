# 📋 5 prestations à coller dans Cal.com (une par une)

Quand tu es connecté sur cal.com → **Event Types** → **New Event Type** → copie-colle chaque bloc ci-dessous.

Pour chaque event type :
- **Title** : le nom de la prestation
- **Duration** : la durée
- **Description** : ce qui est marqué ci-dessous
